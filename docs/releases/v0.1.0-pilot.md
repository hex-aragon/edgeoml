# EdgeOML v0.1.0 M4 pilot

This release publishes the first reproducible EdgeOML feasibility result:
32 synthetic key-response fingerprints inserted into the Apache-2.0
Qwen2.5-1.5B-Instruct model and evaluated before and after GGUF conversion and
quantization on an Apple M4 with 16 GiB unified memory.

## Results

| Condition | Exact match | Wilson 95% CI | Decoy matches |
|---|---:|---:|---:|
| Transformers BF16 | 31/32 (96.88%) | 84.26%-99.45% | 0/256 |
| GGUF BF16 | 30/32 (93.75%) | 79.85%-98.27% | 0/256 |
| GGUF Q8_0 | 31/32 (96.88%) | 84.26%-99.45% | 0/256 |
| GGUF Q4_K_M | 28/32 (87.50%) | 71.93%-95.03% | 0/256 |

The original model produced 0/32 assigned fingerprint responses. The failed
first training checkpoint (7/32) is also retained.

## Included evidence

- 1,184 raw JSONL prediction records;
- fixed model, llama.cpp, and OML audit revisions;
- exact generation, training, conversion, quantization, and evaluation commands;
- environment manifest and SHA-256 artifact digests;
- a standalone release validator and CI across Python 3.11-3.13;
- a five-page Sentient grant brief.

Large model, adapter, and GGUF files are not attached. Their SHA-256 digests
are published so separately hosted artifacts can be verified.

## Scope boundary

This is an OML-style MLX LoRA feasibility pilot. It is not a reproduction of
Sentient's full OML fine-tuning method and does not establish protected
execution, Android performance, removal resistance, or model utility
preservation. Those are proposed grant milestones.
